# Public Assets

This directory contains static assets for the website.

## Required Files

Replace the placeholder files with actual assets:

1. **hero-loop.mp4** - A short (8-12 second) looping video for the hero section
   - Recommended: 1920x1080, MP4 format
   - Should show a "before/after" transformation or property-related content
   - Keep file size optimized (< 5MB if possible)

2. **placeholder-before.jpg** - "Before" image for case studies
   - Recommended: 1200x800px, JPG format
   - Show property in original condition

3. **placeholder-after.jpg** - "After" image for case studies
   - Recommended: 1200x800px, JPG format
   - Show property after renovation/flip

4. **favicon.ico** - Website favicon
   - Standard ICO format (16x16, 32x32, 48x48 sizes)

## Optional Files

- Logo files (SVG preferred)
- Additional case study images
- Trust badge images (if not using emoji)
